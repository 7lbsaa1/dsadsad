# WhiteStudio AI

موقع عربي بسيط لمعالجة الصور الشخصية وإنتاج صورة بخلفية بيضاء باستخدام إزالة الخلفية بالذكاء الاصطناعي داخل المتصفح.

## التشغيل محلياً

1. ثبّت Node.js (إصدار LTS).
2. افتح مجلد المشروع في VS Code.
3. افتح Terminal ونفّذ:

```bash
npm install
npm run dev
```

4. افتح الرابط الذي يظهر في الطرفية، غالباً `http://localhost:5173`.

## البناء والنشر على Vercel

```bash
npm run build
```

ارفع المشروع إلى GitHub ثم استورده في Vercel. الإعدادات الافتراضية:
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

لا تضف متغيرات بيئة أو مفاتيح API.

## ملاحظات مهمة

- المعالجة تتم داخل متصفح المستخدم، ولا يوجد رفع للصورة إلى قاعدة بيانات أو خادم خاص بالمشروع.
- في أول استخدام يتم تنزيل ملفات النموذج وملفات WASM من مصادر المكتبة؛ لذلك يلزم اتصال بالإنترنت وقد يستغرق أول تشغيل وقتاً أطول. بعد ذلك قد يستفيد المتصفح من التخزين المؤقت.
- تحسين الإضاءة والتباين هنا معالجة Canvas تقليدية، وليس تكبيراً حقيقياً بالذكاء الاصطناعي (AI Super Resolution).
- النتيجة تعتمد على جودة الصورة الأصلية. للحصول على أفضل قصّ، استخدم صورة واضحة والشخص فيها منفصل بصرياً عن الخلفية.
- المكتبة `@imgly/background-removal` مرخصة وفق AGPL-3.0. راجع الترخيص والتزامات النشر قبل استخدام المشروع تجارياً أو تقديمه كخدمة مغلقة المصدر: https://github.com/imgly/background-removal-js
- لا تعتبر هذه الأداة بديلاً عن متطلبات الصور الرسمية؛ راجع مواصفات الجهة التي ستقدم لها الصورة، لأن بعض الجهات تشترط أبعاداً ووضعية وإضاءة محددة.
